# Arsenal de edição com IA — prévia

Biblioteca com 201 prompts e perfis editoriais em 18 áreas profissionais. Versão 3.0.1.

Esta prévia pública integral foi autorizada pelo proprietário em 26/10/2026. A hospedagem definitiva será decidida posteriormente.

## Abrir no computador

Baixe o repositório em Code → Download ZIP, extraia a pasta inteira e abra `index.html` no navegador.
Busca, filtros, favoritos, caixas roláveis, botão **Copiar**, ajustes opcionais e downloads funcionam sem servidor ou dependências externas.

## Publicar a prévia no GitHub Pages

No repositório público, abra Settings → Pages. Escolha Deploy from a branch, branch `main`, pasta `/ (root)` e salve.
Aguarde o GitHub concluir a publicação; use o endereço mostrado em Pages. Não há domínio próprio nem senha configurados nesta prévia.

## Conteúdo e validação

Os 201 prompts e perfis tiveram revisão individual editorial e de compatibilidade; cinco ajustes específicos foram aplicados e reconferidos. IDs, áreas, arquivos, hashes, fontes, componentes e paridade entre todas as formas do acervo foram verificados.
Esta revisão não executou 201 edições de vídeo e não representa garantia de ausência de bugs. Os perfis são instruções de direção que o Claude deve implementar no projeto; não são 201 efeitos nativos prontos. Veja `RELATORIO-RESUMIDO.md`.

Claude Code, acesso legítimo à skill do-bruto-ao-pronto e o ambiente de edição são preparados separadamente. Nenhum código, ativo ou biblioteca restrita da skill é redistribuído aqui. O PDF anterior não foi incluído como atualizado.

## Refinar o design ou migrar de hospedagem

O site usa HTML, CSS e JavaScript simples. Pode ser trabalhado no Claude ou em outro editor: `index.html`, `styles.css`, `app.js` e `catalog.js`. Preserve os textos completos, a caixa com rolagem e o rótulo **Copiar**.
